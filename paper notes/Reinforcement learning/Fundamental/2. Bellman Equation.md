> [!abstract] Summary
> - **Core concept — state value** $v_\pi(s)$: the expected return obtained by following $\pi$ from $s$. A larger state value means a better policy.
> - **Core tool — Bellman equation**: a set of **linear** equations that link the values of all states. Solving it for a given $\pi$ is **policy evaluation**.
> - **Action value** $q_\pi(s,a)$: the expected return after taking $a$ in $s$. It matters more directly than $v_\pi$ when searching for optimal policies.

Previous: [[1. Basic Concepts]]

## 2.1 Why are returns important?

![[RL-Fig2-2.png|550]]

Three policies that differ only at $s_1$ ($s_2$ forbidden, $s_4$ target). Starting from $s_1$:
$$
\text{return}_1=\frac{\gamma}{1-\gamma},\qquad
\text{return}_2=-1+\frac{\gamma}{1-\gamma},\qquad
\text{return}_3=0.5\Big(-1+\frac{\gamma}{1-\gamma}\Big)+0.5\frac{\gamma}{1-\gamma}=-0.5+\frac{\gamma}{1-\gamma}
$$
$\text{return}_1>\text{return}_3>\text{return}_2$ for **any** $\gamma$, which matches the intuition. ⇒ The return can evaluate policies.

> [!note] $\text{return}_3$ is really an *average* over two trajectories, i.e., an expected value. It is actually a **state value**.

## 2.2 How to calculate returns? → bootstrapping

![[RL-Fig2-3.png|200]]

A cyclic example with $v_i$ = the return starting from $s_i$.
- **By definition:** $v_1=r_1+\gamma r_2+\gamma^2 r_3+\cdots$ (an infinite sum).
- **By bootstrapping** (the more important way): $v_1=r_1+\gamma v_2,\ v_2=r_2+\gamma v_3,\ v_3=r_3+\gamma v_4,\ v_4=r_4+\gamma v_1$.

The returns **depend on each other**. Bootstrapping means obtaining values from themselves. It looks like an endless loop, but in matrix form it is just a linear system:
$$
v=r+\gamma Pv\quad\Rightarrow\quad v=(I-\gamma P)^{-1}r
$$
This is already the Bellman equation for this simple example. Core idea: **the return from one state depends on the returns from other states.**

## 2.3 State value

Notation: $S_t\xrightarrow{A_t}S_{t+1},R_{t+1}$, where all of these are **random variables**. Discounted return:
$$G_t\doteq R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots$$

> [!definition] State value
> $$v_\pi(s)\doteq\mathbb{E}[G_t\mid S_t=s]$$

- It depends on $s$ (the starting state) and on $\pi$ (which generates the trajectories).
- It does **not** depend on $t$. Once the policy is given, the value is fixed.
- **Return vs. state value:** if both the policy and the model are deterministic, one state always gives the same trajectory, so return = state value. Otherwise the state value is the **mean of the returns** of all possible trajectories.
- Returns don't work for stochastic systems (one state → many returns), so we evaluate policies with **state values** instead: greater state values mean a better policy.

---

## 2.4 Bellman equation

**Derivation.** Start from $G_t=R_{t+1}+\gamma G_{t+1}$:
$$v_\pi(s)=\underbrace{\mathbb{E}[R_{t+1}\mid S_t=s]}_{\text{immediate}}+\gamma\underbrace{\mathbb{E}[G_{t+1}\mid S_t=s]}_{\text{future}}$$

- Immediate term (law of total expectation): $\sum_a\pi(a\mid s)\sum_r p(r\mid s,a)\,r$
- Future term: $\sum_{s'}\mathbb{E}[G_{t+1}\mid S_{t+1}=s']\,p(s'\mid s)=\sum_{s'}v_\pi(s')\sum_a p(s'\mid s,a)\pi(a\mid s)$
  - Key step: $\mathbb{E}[G_{t+1}\mid S_t=s,S_{t+1}=s']=\mathbb{E}[G_{t+1}\mid S_{t+1}=s']$ by the **Markov property**.

> [!important] Bellman equation (elementwise form)
> $$v_\pi(s)=\sum_{a}\pi(a\mid s)\Big[\sum_{r}p(r\mid s,a)\,r+\gamma\sum_{s'}p(s'\mid s,a)\,v_\pi(s')\Big],\quad\forall s\in\mathcal{S}$$

**How to read it**
- $v_\pi(s),v_\pi(s')$ are unknowns. It is a **set of equations, one per state**, not a single equation. Solved together, they are well defined.
- $\pi(a\mid s)$ is given, so solving the equation = **policy evaluation**.
- $p(r\mid s,a),p(s'\mid s,a)$ are the **model**. This chapter assumes it is known; model-free methods come later.

**Equivalent forms found in the literature**
- With the joint distribution $p(s',r\mid s,a)$ (Sutton & Barto's form):
$$v_\pi(s)=\sum_a\pi(a\mid s)\sum_{s'}\sum_r p(s',r\mid s,a)\big[r+\gamma v_\pi(s')\big]$$
- If the reward depends only on the next state, $r(s')$:
$$v_\pi(s)=\sum_a\pi(a\mid s)\sum_{s'}p(s'\mid s,a)\big[r(s')+\gamma v_\pi(s')\big]$$

## 2.5 Examples

| Deterministic policy | Stochastic policy |
|:--:|:--:|
| ![[RL-Fig2-4.png\|200]] | ![[RL-Fig2-5.png\|200]] |

**Deterministic** (left): the general formula collapses to one term per state.
$$v_\pi(s_1)=0+\gamma v_\pi(s_3),\quad v_\pi(s_2)=1+\gamma v_\pi(s_4),\quad v_\pi(s_3)=1+\gamma v_\pi(s_4),\quad v_\pi(s_4)=1+\gamma v_\pi(s_4)$$
$\Rightarrow v_\pi(s_2)=v_\pi(s_3)=v_\pi(s_4)=\frac{1}{1-\gamma},\ v_\pi(s_1)=\frac{\gamma}{1-\gamma}$. With $\gamma=0.9$: $(9,10,10,10)$.

**Stochastic** (right): only $s_1$ changes. It becomes a probability-weighted average of the two branches:
$$v_\pi(s_1)=0.5[0+\gamma v_\pi(s_3)]+0.5[-1+\gamma v_\pi(s_2)]=-0.5+\frac{\gamma}{1-\gamma}\;\xrightarrow{\gamma=0.9}\;8.5$$

$v_{\pi_1}(s_i)\ge v_{\pi_2}(s_i)$ for all $i$ ⇒ the first policy is better. **State values can evaluate policies.**

## 2.6 Matrix-vector form

Define
$$r_\pi(s)\doteq\sum_a\pi(a\mid s)\sum_r p(r\mid s,a)\,r\quad(\text{mean immediate reward}),\qquad p_\pi(s'\mid s)\doteq\sum_a\pi(a\mid s)\,p(s'\mid s,a)$$
Then $v_\pi(s)=r_\pi(s)+\gamma\sum_{s'}p_\pi(s'\mid s)v_\pi(s')$. Stacking all $n=|\mathcal{S}|$ states gives:

> [!important] Bellman equation (matrix-vector form)
> $$v_\pi=r_\pi+\gamma P_\pi v_\pi,\qquad [P_\pi]_{ij}=p_\pi(s_j\mid s_i)$$

Properties of $P_\pi$:
- **Nonnegative**: $P_\pi\ge0$ (elementwise).
- **Stochastic**: each row sums to 1, i.e., $P_\pi\mathbf{1}=\mathbf{1}$.

Example (stochastic policy above):
$$
r_\pi=\begin{bmatrix}-0.5\\1\\1\\1\end{bmatrix},\qquad
P_\pi=\begin{bmatrix}0&0.5&0.5&0\\0&0&0&1\\0&0&0&1\\0&0&0&1\end{bmatrix}
$$

## 2.7 Solving state values (policy evaluation)

### Closed-form solution
$$v_\pi=(I-\gamma P_\pi)^{-1}r_\pi$$
Properties of $(I-\gamma P_\pi)^{-1}$:
1. **$I-\gamma P_\pi$ is invertible.** Proof via the **Gershgorin circle theorem**: circle $i$ has center $1-\gamma p_\pi(s_i\mid s_i)$ and radius $\sum_{j\ne i}\gamma p_\pi(s_j\mid s_i)$. Since $\gamma<1$, the radius is smaller than the center, so no circle contains 0 and no eigenvalue is zero.
2. $(I-\gamma P_\pi)^{-1}=I+\gamma P_\pi+\gamma^2P_\pi^2+\cdots\ \ge I\ \ge 0$.
3. **Monotonicity**: $r\ge0\Rightarrow(I-\gamma P_\pi)^{-1}r\ge r\ge0$. Hence $r_1\ge r_2\Rightarrow(I-\gamma P_\pi)^{-1}r_1\ge(I-\gamma P_\pi)^{-1}r_2$.

Good for theory, but **not practical**: matrix inversion still needs a numerical algorithm.

### Iterative solution
$$v_{k+1}=r_\pi+\gamma P_\pi v_k,\quad k=0,1,2,\dots\qquad v_k\to v_\pi\ \ (k\to\infty)\ \text{for any } v_0$$

> [!example]- Convergence proof (Box 2.1)
> Let $\delta_k=v_k-v_\pi$. Substituting into the iteration and using $v_\pi=r_\pi+\gamma P_\pi v_\pi$ gives $\delta_{k+1}=\gamma P_\pi\delta_k$, so
> $$\delta_{k+1}=\gamma^{k+1}P_\pi^{k+1}\delta_0.$$
> Every entry of $P_\pi^k$ lies in $[0,1]$, and $\gamma^k\to0$, so $\delta_k\to0$.

## 2.8 From state value to action value

> [!definition] Action value
> $$q_\pi(s,a)\doteq\mathbb{E}[G_t\mid S_t=s,A_t=a]$$
> It depends on the **state–action pair** (strictly speaking, it is a "state-action value").

**Two sides of the same coin**
$$
\underbrace{v_\pi(s)=\sum_a\pi(a\mid s)\,q_\pi(s,a)}_{(2.13)\ \text{state value = expectation of action values}}
\qquad
\underbrace{q_\pi(s,a)=\sum_r p(r\mid s,a)\,r+\gamma\sum_{s'}p(s'\mid s,a)\,v_\pi(s')}_{(2.14)\ \text{action value from next-state values}}
$$

### Example and a common mistake
Same stochastic policy as Fig. 2.5 (at $s_1$ the policy only picks $a_2$ or $a_3$):
$$q_\pi(s_1,a_2)=-1+\gamma v_\pi(s_2),\qquad q_\pi(s_1,a_3)=0+\gamma v_\pi(s_3)$$

> [!warning] Common mistake: "the policy never picks $a_1,a_4,a_5$, so their $q$ is 0 / not needed." **Wrong.**
> - Every action has a value, whether or not $\pi$ selects it. Take the action, then follow $\pi$:
> $$q_\pi(s_1,a_1)=-1+\gamma v_\pi(s_1),\quad q_\pi(s_1,a_4)=-1+\gamma v_\pi(s_1),\quad q_\pi(s_1,a_5)=0+\gamma v_\pi(s_1)$$
> - **Why care?** The current policy may be bad and may be missing the best action. To find optimal policies we must keep **exploring** all actions.

Check: $v_\pi(s_1)=0.5\,q_\pi(s_1,a_2)+0.5\,q_\pi(s_1,a_3)$, which matches Sec. 2.5.

### Bellman equation in terms of action values
Substituting (2.13) into (2.14):
$$q_\pi(s,a)=\sum_r p(r\mid s,a)\,r+\gamma\sum_{s'}p(s'\mid s,a)\sum_{a'}\pi(a'\mid s')\,q_\pi(s',a')$$
Matrix form:
$$q_\pi=\tilde r+\gamma P\Pi\,q_\pi$$
- $q_\pi,\tilde r$ are indexed by $(s,a)$, with $[\tilde r]_{(s,a)}=\sum_r p(r\mid s,a)r$.
- $[P]_{(s,a),s'}=p(s'\mid s,a)$.
- $\Pi$ is block-diagonal, with $\Pi_{s',(s',a')}=\pi(a'\mid s')$.
- **Feature:** $\tilde r$ and $P$ depend **only on the model**. The policy enters only through $\Pi$. It is also a contraction mapping with a unique solution.

## Key takeaways (Q&A)

| Question | Answer |
|---|---|
| State value vs. return? | The state value is the **mean of the returns** starting from that state. |
| Why care about state values? | They evaluate policies; **optimal policies are defined through them** (Ch3). |
| Why the Bellman equation? | It describes the relationships among the values of all states and is the tool for analyzing them. |
| Why is solving it called *policy evaluation*? | Its solution (the state values) tells us how good the policy is. |
| Why the matrix-vector form? | It is a set of linear equations, one per state, and the matrix form expresses them all at once so they can be solved. |
| State value vs. action value? | $v$ = mean of $q$ over the policy; $q$ = immediate reward + discounted values of the next states. |
| Why compute $q$ for actions $\pi$ never picks? | Those actions may be better. Finding optimal policies requires **exploration**. |

> [!tip] Bootstrapping
> The most confusing idea for beginners is that a state's value depends on other states' values, which may depend back on it. Viewed through the matrix-vector form it is simply a linear system. The Bellman equation also appears in control theory and operations research.
